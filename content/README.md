# Учебный контент

Материалы хранятся отдельно от маршрутов: `modules/<номер>/<раздел>/ru.ts`, `kz.ts`, `en.ts`.
Каждый файл экспортирует объект `Lesson` из `types.ts`: название, тематические разделы, результаты обучения и ключевые термины.
Блоки поддерживают абзацы, подзаголовки, списки и выделенные идеи. Текст — обычные строки, без HTML.

Для нового материала создайте три языковых файла и зарегистрируйте их в `index.ts` под номером модуля (1–23) и разделом (`theory`, `practice`, `cases`, `tests`, `questions`, `media`).
Тип `LocalizedLesson` требует все три языка. `getLesson` возвращает материал выбранного языка либо `undefined`, если раздел ещё не заполнен.

Маршрут выбирает материал по параметрам URL. `components/LessonContent.tsx` отвечает за отображение и использует изолированные стили CSS Modules. Текст не нужно добавлять в `page.tsx`.

## Практические занятия

Файлы `modules/<номер>/practice/{ru,kz,en}.ts` экспортируют `PracticeLesson` с `kind: "practice"`. Помимо обычных текстовых блоков доступны `response` (поле самостоятельного ответа), `answer` (закрытый раскрываемый ответ), `sequence` (выбор и проверка последовательности), `table` (заполняемая таблица с отдельными эталонами), `checklist` (самооценка).

В `sequence.steps` задаётся правильный порядок; компонент сам перемешивает варианты для отображения. В `table.rows` каждая строка содержит название структуры и два эталонных ответа. До раскрытия ответов студент видит пустые поля. Свободные ответы проверяются самостоятельно по эталонам, автоматически проверяется только последовательность. Строки интерфейса задаются в `ui` на языке материала.

`components/PracticeContent.tsx` и его CSS Module обслуживают только практические занятия. Состояние упражнений локальное: оно сбрасывается при перезагрузке или смене языка. Новые библиотеки и изменения компонента теории не требуются.
