2. При слиянии PR возможны конфликты в `content/course-foundation/index.ts`, `app/modules/[id]/[section]/page.tsx` и `package.json`. Требуется последовательная интеграция с сохранением изменений всех веток.
3. В `ExamCenter.tsx` не подтверждён экзаменационный таймер; не обещать его студентам до реализации и проверки.
4. Проверки исходного кода не доказывают корректность отображения на мобильном устройстве, доступность для клавиатуры/скринридера, научную точность каждого задания, лицензии на все изображения или доступность внешних ссылок.
